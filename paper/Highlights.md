# Highlights

- Open-source Gibbs energy minimizer in dependency-free C for MQMQA slags, salts and CEF alloys
- First freely licensed MQMQA oxide slag database, from published data with provenance
- Builds new databases from measured data at any number of components, free and open
- Runs fully in the browser via WebAssembly: zero install, nothing transmitted
- Reads ChemSage, Thermo-Calc, unified uTDB, and third-generation XTDB formats
- Energy terms reproduce pycalphad, from which the MQMQA core is translated; gas checked against Cantera
